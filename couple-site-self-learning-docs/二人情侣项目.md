# 二人情侣项目

我主要是想通过这个来就行一个练手，现在主要做几个功能：

1. 时间轴：可以再这上面发动态，按照时间进行排序的，可以很长；
2. 纪念日：一些重要时刻；
3. 相册：因为现在存了很多相册了，可以进行一个保存；

后续还可以拓展其他功能，我想的是后面还要加：

1. 二人聊天，小游戏；
2. 增加agent模块，引入一个智能旅行助手；
3. 每日任务清单，每日总结；

现在目前就想了这么多。想做这个的目的除了练手，还因为我觉得有一个自己的网站可以记录我们两个人的一生还是非常有意思的，我觉得这个特别对于那种异地恋的情侣，更加有用，因为这个算是属于二人的私人空间了，可以进行一个管理，多年之后还可以拿来看，不会因为其他原因丢失重要信息。

后端包结构建议：

```
com.couple/
├── config/          # Security、CORS、MyBatis-Plus 配置
├── common/          # 统一响应封装(R)、异常处理、常量
├── auth/            # 登录/注册/JWT
├── user/            # 用户管理
├── couple/          # 情侣关系（核心！）
├── moment/          # 时间轴
├── anniversary/     # 纪念日
├── album/           # 相册
└── file/            # 文件上传
```

### 前端（vue3）

```
pnpm create vue@latest frontend
# 选 TypeScript、Vue Router、Pinia、ESLint、Prettier

cd frontend
pnpm add element-plus axios
pnpm add -D @types/node
```

目录结构

```
src/
├── api/             # 按模块分：auth.ts, user.ts, moment.ts...
├── stores/          # Pinia：auth.ts, couple.ts
├── router/          # 路由配置
├── layouts/         # 布局组件（登录页用空白布局，主应用用带侧边栏的布局）
├── views/           # 页面：Login, Register, Home, Timeline, Album...
├── components/      # 公共组件
├── utils/           # axios 封装、工具函数
└── types/           # TypeScript 类型定义
```

## 三阶段：JWT 认证 + 前后端联调

**后端重点：**

1. 配置 Spring Security，放行 `/auth/**`，其他接口验证 JWT
2. 编写 `JwtAuthenticationFilter`
3. 封装统一响应：`Result<T>`（code, message, data）
4. 配置 CORS 允许前端 `localhost:5173`

**前端重点：**

1. 封装 Axios（请求拦截器自动带 Token，响应拦截器处理 401）
2. Pinia 管理登录状态（token, userInfo）
3. 路由守卫（未登录跳转登录页）
